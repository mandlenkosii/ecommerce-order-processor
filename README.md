# E-Commerce Order Processor

## Project Description

This project is a simple e-commerce order management application built with JavaScript. It allows users to view orders, clean customer information, calculate prices, search and filter orders, find products, process JSON data and validate information.

## Technologies Used

- HTML
- Tailwind CSS
- JavaScript

## JavaScript Built-In Objects and Methods

| Built-in | How I used it                                        |
| -------- | ---------------------------------------------------- |
| String   | Clean customer names and emails                      |
| Number   | Convert and format prices                            |
| Math     | Find the highest and lowest prices                   |
| Date     | Format order dates and identify recent orders        |
| Array    | Search, filter, sort and calculate order information |
| Set      | Display unique product categories                    |
| Map      | Find product details by product name                 |
| JSON     | Export and import order data                         |
| RegExp   | Validate emails and order IDs                        |

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or a web browser.
4. Use the buttons and input fields to test the application.

An internet connection is required to load Tailwind CSS from its CDN.

## Reflection

### 1. Which built-in JavaScript object did you find most useful?

I found Array methods useful because I in a sense already new them but using the in the practical sense helped me search, filter and calculate information without writing complicated loops.

### 2. Which challenge was the most difficult?

The JSON challenge was difficult because I had to convert data, check for errors and make sure imported orders did not have duplicate IDs.

### 3. What did you learn about choosing the right JavaScript method for a problem?

I learned that different methods have different purposes. For example, `filter()` finds multiple matching items, `find()` returns the first match, and `Set` removes duplicate values.

### 4. If you had more time, what would you improve?

I would add the ability to edit and delete orders, improve the design and allow users to save their data between sessions. Also having to understand everything/concept to its core
